# Orbital Array Mk2: full structure pattern

Generated from `ORBITAL_MK2_SLICES` in kubejs/startup_scripts/gtceu/photolithography.js (main, after the ring-clearance and coil rework). 73 x 130 x 73 cells, controller at the centre of level 0 (top).

Each level below is a top-down view (north/front = first row, x = columns, 73x73). Levels are numbered by blocks below the controller (d). `.` = any block / air. Controller at row 36, column 36 of level 0.

## Legend

- `K` Controller (Orbital Lithography Station), faces up
- `A` gtceu:hsse_frame (unused in Mk2 tower)
- `S` gtceu:superconducting_coil (core tube)
- `B` any heating coil (tier = bonus): six square collars round the core tube, inside the walls (never on the outside)
- `D` af9:orbital_truss_casing (was gtceu:sturdy_machine_casing; the inner half of the rings' bands, docs/orbital-casings.md)
- `E` af9:orbital_girder_casing (was gtceu:sturdy_machine_casing; the outer half of the rings' bands)
- `F` gtceu:tungsten_carbide_frame (Mk2)
- `M` af9:orbital_magnet_casing
- `N` af9:orbital_light_casing (a straight light seam up the middle of each wall panel, between the magnet pillars)
- `H` gtceu:atomic_casing (Mk2)
- `L` af9:orbital_combined_structure_casing (was gtceu:stress_proof_casing; also the halo ring and its struts)
- `Q` af9:orbital_deck_casing (was gtceu:inert_machine_casing; above/below module slot)
- `Y` module slot: Orbital Module or air
- `C` gtceu:nonconducting_casing
- `O` af9:orbital_deck_casing (was gtceu:inert_machine_casing) OR any hatch (top deck/crown: energy, laser, coolant, computation, data, optical, fluid in, item in/out, maintenance)

## Ring clearance

Each turning ring sweeps a clear annulus (its light ring sits at radius - width - 1.5, af9-core `Band.lightRadius`). Nothing that stands
still comes within 1.75 blocks inside that light ring: the deck plates round the tower are cut to that circle
(`orbitalClear` in photolithography.js). Closest static block to a light ring: 1.2 blocks (ring at level 22), 1.7 (level 40), 1.15 (level 58).
The four beams are plasma in game (their blocks are hidden and the beam is drawn to the band), so they do not count.
