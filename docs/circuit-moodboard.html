Circuit Foundry — how AF9 circuits are crafted & what they need

A moodboard of the linear ladder LV → MV → HV → EV → IV → LuV → ZPM → UV → UHV → Pico: every normal circuit takes the tier below, the value sits in lithographed dies and packages, and each finished stage unlocks a lean second recipe for everything beneath it.

Lean stages — finish a stage, reprint everything below it

Same chain, 1× previous circuit, packages instead of loose chips, quarter wires/bolts, no loose passives, 2× output or half time. The normal recipe always stays.

House rules (load-bearing)

  • LINEAR — every circuit takes ≥1× the tier below; SoC never skips a tier
  • SILICON FIRST — value in dies & packages; boards are carriers; metals shrink, then collapse in lean
  • Boards climb — phenolic → plastic → epoxy → fiber → multilayer → wetware PCB

Packages — 1 package instead of 4–16 loose chips

  • af9:asic_package — asic + 2 RAM + epoxy + Au (HV assembler, cleanroom) → EV lean
  • af9:edram_cpu_package / edram_soc_package — cache for the IV/LuV lines → IV lean, LuV normal + lean, nano mainframe AL ×8
  • af9:photonic_package — photonic + 2 spin + europium + sanguinite, plasma 36 mB (UHV, cleanroom)
