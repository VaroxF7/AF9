GET STARTED

Install & build

  1. Go to Actions → Build AF9 Core → latest run → Artifacts and download AF9-update.
  2. Extract it into the instance folder (the one containing mods/) and let it overwrite. Delete any older af9-core-*.jar.
  3. Requires GregTech CEu Modern 7.2.0 + Ad Astra 1.15. Jade & Curios optional. Every client and server needs the jar.

The artifact ships mods/af9-core-<version>.jar + kubejs/ + config/ of that commit, plus AF9_BUILD.txt with the commit hash.

cd af9-core
./gradlew build        # Windows: gradlew build
# jar → af9-core/build/libs/af9-core-<version>.jar → instance mods/

Needs JDK 17. Versions pinned in af9-core/gradle.properties to what GTCEu 7.2.0 was built against — bump together with the pack.

bash tools/lint/run.sh            # full check, no game needed
bash tools/lint/run.sh --selftest # + self-test (what CI runs)

CI on pushes to main (af9-core/, kubejs/, config/, tools/lint/): lint → build → package (af9-core + AF9-update artifacts). Findings: docs/review-findings.md.
